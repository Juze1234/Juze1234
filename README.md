### Selected systems

| System | What it does |
| --- | --- |
| Loadout selection | Config-driven equipment sets tied to a character's home station, with live preview and server-side validation |
| Roleplay infrastructure | Player identity and passports, rental, access control, private storage |
| Power network | Generators driving lighting circuits, control panels and powered hermetic doors |
| Rail handcars | Rideable multiplayer rail vehicle on custom track layouts with automatic node alignment |
| Environmental hazards | Layered electric anomalies that damage players, drain batteries and cut vehicle power |
| Radiation | Contaminated zones with safe-zone overrides, consumable gas-mask filters, and a wristwatch repurposed into a filter countdown with audible warnings |
| Sanity | Psychic pressure scaled by distance, view angle and line of sight; resistance earned through kills; dropped items and dropped backpacks as sanity falls |
| Character cards | Persistent roleplay dossiers with a replicated portrait and written descriptions, stored per player |
| Radio comms | Server-side voice router over the engine's proximity VOIP: a per-pair mute matrix recomputed each tick from position, tuned frequency and radio state, including relay through a radio left on speaker |
